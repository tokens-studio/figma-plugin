Tokens Studio projects in Simple view: Manage themes now shows collections and modes. You can add, rename and delete them, reorder modes, pick the default mode and copy values between modes. The token set tree offers "Add collection" and "Add mode" instead of "New set", and renaming a set renames its mode or collection. When Tokens Studio refuses a change, the plugin explains why in its own words and reloads the project. Other projects work as before.
